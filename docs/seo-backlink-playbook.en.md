## Link Targets by Intent

Do not point every backlink to the homepage. Matching the page to the reader's intent is more natural and builds stronger topical relevance.

| Scenario | Recommended URL | Anchor text examples |
| --- | --- | --- |
| Introduce the overall project | https://codexthemes.app/ | CodexThemes.app, Codex themes website |
| Recommend the theme gallery | https://codexthemes.app/themes | browse Codex themes, Codex App themes |
| Promote the desktop app | https://codexthemes.app/desktop-app | Codex theme manager, Codex Themes Desktop |
| Publish a tutorial | https://codexthemes.app/guides/how-to-install-codex-theme | how to install a Codex theme |
| Discuss terminal customization | https://codexthemes.app/codex-cli-themes | Codex CLI themes |
| Answer common questions | https://codexthemes.app/faq | Codex Themes FAQ |

## Anchor Text Mix

| Anchor type | Suggested share | Examples |
| --- | --- | --- |
| Brand anchors | 35% | CodexThemes.app, Codex Themes Desktop |
| Partial-match anchors | 35% | custom Codex themes, Codex theme manager |
| Naked URLs | 15% | https://codexthemes.app/ |
| Generic anchors | 10% | this theme gallery, the install guide |
| Exact-match anchors | 5% | Codex themes |

Keep exact-match anchor text sparse. Good link building should read like a real recommendation, not repeated keyword placement.

## README Checklist

- H1 includes `Codex Themes Desktop` and `Codex App Theme Manager`.
- The first 150 words define the product and mention `Codex App`, `Codex Desktop`, `Codex themes`, and `theme manager`.
- The top section links to the homepage, theme gallery, desktop app page, installation guide, and CLI themes page.
- Chinese and English README files link to each other, with English serving as the primary global developer version.
- FAQ headings use question-style phrasing for Google and AI answer extraction.
- The README clearly states that the project is independent and not affiliated with OpenAI.

## GEO Notes

- The first paragraph should directly answer “What is Codex Themes Desktop?”
- Use comparison tables for Codex App themes, Codex Dream Skin, and Codex CLI themes.
- State limitations clearly: independent project, no official package mutation, screenshots are previews only.
- Add FAQ sections for queries such as “What is Codex Themes Desktop?”, “How do I install a Codex theme?”, and “How are Codex CLI themes different from desktop themes?”
