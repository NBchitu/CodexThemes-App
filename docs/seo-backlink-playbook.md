## 锚文本比例

| 类型 | 建议比例 | 示例 |
| --- | --- | --- |
| 品牌锚文本 | 35% | CodexThemes.app, Codex Themes Desktop |
| 部分匹配关键词 | 35% | custom Codex themes, Codex theme manager |
| URL 裸链 | 15% | https://codexthemes.app/ |
| 泛锚文本 | 10% | this theme gallery, the install guide |
| 精确匹配关键词 | 5% | Codex themes |

精确匹配锚文本不要过量。外链发布更像正常推荐，而不是机械重复关键词。

## README 发布清单

- H1 包含 `Codex Themes Desktop` 和 `Codex 桌面端主题管理器`。
- 前 150 字直接定义产品，覆盖 `Codex App`、`Codex Desktop`、`Codex themes`、`theme manager`。
- 首屏放官网、主题库、桌面端下载、安装指南和 CLI 主题页。
- 中英 README 互链，并保持英文 README 为全球开发者主版本。
- FAQ 使用问题型标题，方便 Google 和 AI 系统抽取。
- 明确声明非 OpenAI 官方产品，不声称官方背书。

## GEO 内容要点

- 每篇外部内容第一段直接回答“Codex Themes Desktop 是什么”。
- 使用对比表说明 Codex App themes、Codex Dream Skin、Codex CLI themes 的区别。
- 提供清楚限制：不是官方产品、不修改官方安装包、截图不可当作背景导入。
- 用 FAQ 覆盖问题型查询，例如“Codex Themes Desktop 是什么？”“如何安装 Codex 主题？”“Codex CLI themes 和桌面主题有什么区别？”
