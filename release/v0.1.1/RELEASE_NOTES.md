# Codex Themes v0.1.1 for macOS

## Downloads

- Apple Silicon (M1, M2, M3, M4 and newer):
  `Codex-Themes-v0.1.1-macOS-Apple-Silicon-arm64.dmg`
- Intel Mac:
  `Codex-Themes-v0.1.1-macOS-Intel-x86_64.dmg`

Open the correct DMG for your Mac and drag Codex Themes to Applications.

## First launch / 首次打开

This community build is ad-hoc signed but is not notarized by Apple. If macOS
blocks the first launch, open **System Settings > Privacy & Security** and click
**Open Anyway**.

此社区版本已经过 Ad-hoc 完整性签名，但尚未经过 Apple 公证。如果 macOS 阻止首次运行，
请打开 **系统设置 > 隐私与安全性**，然后点击 **仍要打开**。
