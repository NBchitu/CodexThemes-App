# Codex Themes v0.1.2 for macOS

## What changed

- Finder can hand a `.codextheme` to the App during cold launch without requiring a second double-click.
- Import confirmation is shorter; an installed theme now offers Replace or Cancel.
- My Themes is the first and default destination.
- Run Codex and in-App notifications use a more compact presentation.
- Runtime verification keeps whole-bundle validation as the preferred path and supports official installations whose nested helper seals differ after an update, while still verifying the official Team ID, signed Node runtime, and exact executable.

## Downloads

- Apple Silicon: `Codex-Themes-v0.1.2-macOS-Apple-Silicon-arm64.dmg`
- Intel Mac: `Codex-Themes-v0.1.2-macOS-Intel-x86_64.dmg`

Open the correct DMG and drag Codex Themes to Applications. Replace v0.1.1 when macOS asks.

## First launch / 首次打开

This community build is ad-hoc signed but is not notarized by Apple. If macOS blocks the first launch, open **System Settings > Privacy & Security** and click **Open Anyway**.

此社区版本已经过 Ad-hoc 完整性签名，但尚未经过 Apple 公证。如果 macOS 阻止首次运行，请打开**系统设置 > 隐私与安全性**，然后点击**仍要打开**。
