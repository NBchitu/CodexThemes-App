# Codex Themes v0.1.3 for macOS

## What changed

- Supports the updated Codex `26.715.71837` signing layout while retaining OpenAI Team ID, signed Node runtime, and exact executable verification.
- Recovers the UI from stale or timed-out Launching state and re-enables Apply Theme automatically.
- Isolates Codex process discovery by the current macOS user when multiple accounts are active.
- Uses compact auto-dismissing status notifications and distinguishes Theme applied from Theme reapplied.
- Keeps the v0.1.2 cold-start `.codextheme` import, concise confirmation, and rollback-safe replacement fixes.
