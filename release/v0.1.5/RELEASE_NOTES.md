# Codex Themes v0.1.5 for macOS

## What changed

- Adds dual-path renderer detection for both legacy Codex builds and Codex 26.727's new main-content structure.
- Restores theme injection, verification, and automatic re-application after the current Codex App is reopened.
- Fixes themes whose colors applied successfully while their background image remained hidden on the new main-content surface.
- Keeps avatar-overlay and other auxiliary renderer targets excluded from injection.
- Fixes current Codex process detection on macOS while retaining compatibility with older `Codex` process names.
- Preserves the existing `.codextheme` package schema and saved window-effect preferences.
- Includes the previously completed animated Electric edge and pixel-cat improvements.
