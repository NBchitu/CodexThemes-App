# Codex Themes branding

`codexthemes-logo-mark-512.png` is the canonical raster source used to generate
the native application icon set with the Tauri icon generator.

The in-app vector mark is maintained separately at
`desktop-app/src/assets/brand/codexthemes-logo-mark.svg` so it remains crisp at
small Retina display sizes.

Generated macOS, Windows, iOS, and Android icon assets live under
`desktop-app/src-tauri/icons/`.
